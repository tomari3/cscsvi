#### שאלה 1

הריצו `FFT` מסדר 4, על מקדמי הפולינום $p(x)=x^3+2x^2-3x-1$

בתרגיל זה $n=4$, נקבע $w=e^{\tau i/4}$
נחשב את $FFT((-1,-3,2,1),w)$

```
Calling FFT((-1,-3,2,1),w = i)
	Calling FFT((-1,2),w^2 = -1)
		Calling FFT((-1),w^4 = 1) → (-1)
		Calling FFT((2),w^4 = 1) → (2)
		return (-1+1*2,-1-1*2) → (1,-3)
	Calling FFT((-3,1),w^2 = -1)
		Calling FFT((-3), w^4 = 1) → (-3)
		Calling FFT((1), w^4 = 1) → (1)
		return (-3+1*1,-3-1*1) = (-2,-4)
	Calculate f(1) = 1+1*(-2) = 2, 
			f(i) = -3 + i*(-4) = -3 + -4i
			f(-1) = 1 + (-1) * (-2) = 3
			f(-i) = -3 + (-i) * (-4) = -3 + 4i
	return (2,-3-4i,3,-3+4i)
```

#### שאלה 2

מצאו אלגוריתם לכפל מספרים שלמים המשתמש ב `FFT` וזמן הריצה שלו הוא $O(n\log^2n)$

נסמן $a,b\in \mathbb{Z}$. נבצע המרה לצורה בינארית פעולה שלוקחת $O(n)$. נסמן את אורך המחרוזת הבינארית $n$
נסמן $k$ מספר שלם המחלק את $n$ ונחלק את $a$ ל$\frac{n}{k}$ בלוקים בגודל $k$ אפשר לייצג את $a$ כסכום ההצגה הבינארית שלו כך:

$$
a=\sum_{i=0}^{\frac{n}{k} -1}2^{ki}a_{i}
$$

אזי התוצאת הכפל בין ההצגות הבינאריות תהי

$$
a\cdot b=\left( \sum_{i=0}^{\frac{n}{k} -1}2^{ki}a_{i} \right)\left( \sum_{j=0}^{\frac{n}{k} -1}2^{kj}a_{j} \right)
$$

נתייחס אל $\hat{a},\hat{b}$ כוקטורים המייצגים את מקדמי $a,b$ ונבחין שכפל הביטויים הוא בעצם קונבולוציה. לכן, נוכל להשתמש ב `FFT` לחשב את התוצר שלהם. 

$$
a\cdot b=\sum_{l=0}^{2(\frac{n}{k}-1)}2^{kl}(\hat{a}*\hat{b})_{l}
$$

נחשב שני וקטורים באורך $\frac{n}{k}$ בזמן $\Theta\left( \frac{n}{k}\log \frac{n}{k} \right)$, הכפל בין שני מספרים שלמים בעלי $k$ ביטים לוקח $\Theta(k^2)$ אזי נקבל 

$$
\Theta\left( k^2 \frac{n}{k}\log \frac{n}{k} \right)=\Theta\left( nk \log \frac{n}{k} \right)
$$

נציב $k=\log n$ לפי הגדרת השאלה ונקבל

$$
\Theta\left( nk\log \frac{n}{k} \right)=\Theta\left( (n\log n)\log\left( \frac{n}{\log n} \right) \right)=\Theta((n\log^2 n))
$$

לאחר מכן נוכל להשתמש ב `IFFT` ולסכום על מנת לקבל $c=ab$
