# שאלה 1
1. כיצד ניתן לייצג ערמה d-ית במערך?
מערך עדיפויות כאשר האיבר בעדיפות $1$ הוא שורש הערמה. האיברים במיקומים $1\to d$ הם הילדים של, $d^2$ הנכדים שלו ו $d^i$ הילדים מדרגה $i$ שלו. כל ילד, מיקום אביו יהי $\frac{i-1}{d},i>0$ וילדיו יהיו במיקומים $di+1\to di+d$
נקרא לשגרות

- `parent(i)`: $\lfloor (i-2)/d \rfloor + 1$ עבור $i > 1$.
- `child(i, j)`: $d \times (i-1) + j + 1$ עבור $1 \le j \le d$. 

2. מה גובהה של ערמה d-ית במונחי $d,n$
$\log_{d}n$

3. מימוש יעיל של Extract-Max בערמת מקסימום $d$-ית. ניתוח במונחי $d,n$

השגרה `max_heapify` צריכה לעבור על כל d הילדים האפשריים כדי למצוא את הגדול ביותר (במקום רק 2 בערמה בינארית). לכן, בכל רמה בעץ היא מבצעת $O(d)$ השוואות.
מכיוון שגובה העץ הוא $O(\log_d n)$, זמן הריצה הכולל של `max_heapify` ושל `extract_max` (שקוראת לה פעם אחת) אכן $O(d \log_d n)$.

```py
def extract_max(A):
	max = A[1]
	A[1] = A[A.size]
	A.size = A.size - 1
	MAX-HEAPIFY(A,1)
	return max
```

```py
def max_heapify(A,i):
	largest = i
	for k =1 to d
		if child(i,k) <= A.size and A[child(i,k)] > A[largest]
			largest = child(i,k)
	if largest != i
		exchange A[i] with A[largest]
		max_heapify(A,largest)
```

4. מימוש יעיל של Insert וניתוח במונחי $d,n$
הפעולה כוללת מעבר ממקום ההכנסה (עלה) עד לשורש במקרה הגרוע. מכיוון שגובה העץ הוא $O(\log_d n)$, זמן הריצה של `insert` הוא $O(\log_d n)$.

```py
def insert(A,key):
	A.size = A.size + 1
	A[A.size] = key
	i = A.size
	while i > 1 and A[parent(i)] < A[i]
		exchange A[i] with A[parent(i)]
		i = parent(i)
```

# שאלה 2
ממש ערימת $d$ בדומה ל שאלה 1 עם הממשק הבא:
1. Build_Max_D_Heap: בניית ערימת $d$ חדשה עבור $d$ הניתן כקלט, עם ערכים הניתנים כקלט, בזמן לינארי. 
2. Change_D: הערימה נשארת עם אותם ערכים ומשנה את $d$ בהתאם לקלט, בזמן לינארי
3. Extract_Max
4. Insert
5. Print
6. Quit
---
1. **`Build_Max_D_Heap(d, values)`**:
    
    - **פעולה**: יוצרת ערמת מקסימום d-ית חדשה מהערכים הנתנים במערך `values`.
    - **מימוש**: בדומה לבניית ערמה בינארית (סעיף 6.3 בספר ), ניתן לבנות ערמה d-ית בזמן לינארי, $O(n)$. מתחילים מהצומת הפנימי האחרון (שאינדקסו $\lfloor n/d \rfloor$ בערך) ויורדים עד לשורש (אינדקס 1), תוך קריאה ל-`max_heapify` (הגרסה ה-d-ית) עבור כל צומת. הניתוח המראה שזמן הריצה הוא לינארי דומה לניתוח עבור ערמה בינארית.  
        
    - **זמן ריצה**: $O(n)$.
2. **`Change_D(heap, new_d)`**:
    
    - **פעולה**: משנה את פרמטר ה-d של הערמה הקיימת `heap` ל-`new_d` מבלי לשנות את הערכים המאוחסנים בה.
    - **מימוש**: מכיוון שהיחסים המבניים (הורה-ילד) תלויים ב-d, שינוי פרמטר זה מחייב ארגון מחדש של הערמה. הדרך הפשוטה ביותר לעמוד בדרישת הזמן הלינארי היא לבנות מחדש את הערמה מאותם הערכים עם ה-d החדש, באמצעות קריאה ל-`Build_Max_D_Heap(new_d, heap.values)`.
    - **זמן ריצה**: $O(n)$.
3. **`Extract_Max`**:
    
    - **פעולה**: מוציאה ומחזירה את האיבר המקסימלי מהערמה.
    - **מימוש**: כפי שתואר בשאלה 1.3: שומרים את ערך השורש (המקסימום), מחליפים את השורש באיבר האחרון בערמה, מקטינים את גודל הערמה ב-1, וקוראים ל-`max_heapify` על השורש (אינדקס 1) כדי להחזיר את תכונת הערמה.  
        
    - **זמן ריצה**: $O(d \log_d n)$.
4. **`Insert`**:
    
    - **פעולה**: מכניסה איבר חדש לערמה.
    - **מימוש**: כפי שתואר בשאלה 1.4: מגדילים את גודל הערמה ב-1, מציבים את האיבר החדש במקום הפנוי האחרון (העלה החדש), ו"מעלים" אותו במעלה העץ באמצעות השוואות והחלפות עם אביו עד להחזרת תכונת הערמה.  
        
    - **זמן ריצה**: $O(\log_d n)$.
5. **`Print`**:
    
    - **פעולה**: מדפיסה את איברי הערמה (למשל, את המערך המייצג אותה).
    - **מימוש**: פשוט לעבור על המערך המייצג את הערמה ולהדפיס את האיברים מהאינדקס הראשון עד האינדקס המציין את גודל הערמה הנוכחי.
    - **זמן ריצה**: $O(n)$.
6. **`Quit`**:
    
    - **פעולה**: מסיימת את התוכנית או האינטראקציה.
    - **מימוש**: פונקציית יציאה סטנדרטית.
    - **זמן ריצה**: O(1).
