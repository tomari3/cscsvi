הוכיחו או הפריכו כל אחת מהטענות:

# פתרון 1

# א
ביטוי: $\lim_{ n \to \infty }\sqrt{ \frac{{4n+1}}{n} }=2$
הגדרת גבול: $\forall \varepsilon>0,\exists N\in \mathbb{N},\forall n>N,|a_{n}-L|<\varepsilon$
סדרה: $a_{n}=\sqrt{ \frac{{4n+1}}{n} }$
גבול: $L=2$
צ״ל: $|a_{n}-L|<\varepsilon=|\sqrt{ \frac{{4n+1}}{n} }-2|<\varepsilon$

יהי $\varepsilon>0$ 

מחוקי שורשים נוכל לרשום

$$
|\sqrt{ \frac{{4n+1}}{n} }-2|=|{\frac{\sqrt{ 4n+1 }}{\sqrt{ n }}-2}|=|\frac{\sqrt{ 4n+1 }-2\sqrt{ n }}{\sqrt{ n }}|
$$

נבחין כי $\sqrt{ 4n+1 }+2\sqrt{ n }>0$ ונבצע כפל בצמוד

$$
| \frac{{(\sqrt{ 4n+1 }-2\sqrt{ n })(\sqrt{ 4n+1 }+2\sqrt{ n })}}{\sqrt{ n }(\sqrt{ 4n+1 }+2\sqrt{ n })}|=|\frac{{4n+1-4n}}{\sqrt{ n }(\sqrt{ 4n+1 }+2\sqrt{ n })}|=|\frac{1}{\sqrt{ n }(\sqrt{ 4n+1 }+2\sqrt{ n })}|
$$

נבחין כי $\sqrt{ n }>0$ ונקטין את המכנה

$$
\frac{1}{\sqrt{ n }(\sqrt{ 4n+1 }+2\sqrt{ n })}> \frac{1}{\sqrt{ n}(\sqrt{ 4n }+2\sqrt{ n }) }= \frac{1}{\sqrt{ n }(2\sqrt{ n }+2\sqrt{ n })}= \frac{1}{\sqrt{ n }4\sqrt{ n }}= \frac{1}{4n}
$$

 ומצאנו ש $\frac{1}{4n}<\varepsilon$ ולכן $n> \frac{1}{4\varepsilon}$ וסך הכל נקבל:
$$
|\sqrt{ \frac{{4n+1}}{n} }-2|< \frac{1}{4n} < \frac{1}{4 \frac{1}{4\varepsilon}}=\varepsilon
$$

אזי מצאנו $N> \frac{1}{4\varepsilon}$

$$
a_{n}=\lim_{ n \to \infty } \sqrt{ n^2 +(-1)^n}-n
$$

$\forall n\in \mathbb{N},n^2+(-1)^n\geq n^2-1\geq0$ הסדרה מוגדרת
$\sqrt{ n^2+(-1)^n }\geq0\implies \sqrt{ n^2+(-1)^n }+n\geq n>0$
נכפול בצמוד
$$
\begin{align}
\sqrt{ n^2+(-1)^n }-n= \frac{{(\sqrt{ n^2+(-1)^n }-n)(\sqrt{ n^2+(-1)^n }+n)}}{\sqrt{ n^2+(-1)^n }+n} \\
= \frac{{n^2+(-1)^n-n^2}}{\sqrt{ n^2+(-1)^n }+n}
\end{align}
$$

$\lim_{ n \to \infty }a_{n}=0\iff \lim_{ n \to \infty }|a_{n}|=0$
הראנו שהביטוי חיובי ומתכונות ערך מוחלט נקבל
$0\leq |\sqrt{ n^2+(-1)^n }-n|=| \frac{{(-1)^n}}{\sqrt{ n^2+(-1)^n }+n}|={\frac{|(-1)^n|}{|\sqrt{ n^2 +(-1)^n}+n|}=\frac{1}{\sqrt{ n^2+(-1)^n }+1}\leq \frac{1}{n}}$

מתוך גבולות ידועים ומשפט הסנדוויץ:
$\lim_{ n \to \infty }0=0,\lim_{ n \to \infty } \frac{1}{n}=0\implies \lim_{ n \to \infty }|a_{n}|=0\implies \lim_{ n \to \infty }a_{n}=0$

# פתרון 3

יהיו $(a_{n}),(b_{n})$ סדרות כך שמתקיים $\lim_{ n \to \infty }a_{n}b_{n}=\infty$
הוכיחו או הפריכו:

1. אם כמעט כל איברי הסדרות חיוביים, אז אחת מהן שואפת לאינסוף
לא נכון. נראה ד.נ:

נוכל להראות שני סדרות חסומות אשר כפל האיברים שלהם, בהתאמה, אינו חסום ואף שואף לאינסוף. לדוגמא:

$$
a_{n}=\begin{cases}
1 & n=2k-1 \\
n & n=2k
\end{cases}, b_{n}=\begin{cases}
n & n=2k \\
1 & n=2k-1
\end{cases}
$$

בכל מקרה מכפלה בין הסדרות כל איבר שווה ל $n$ אשר ברור ששואף לאינסוף אבל בנפרד, שני הסדרות חסומות עבור איברים זוגיים ואי זוגיים בהתאמה. שכן כל איבר שני הוא 1, לפי הגדרת הסדרות
   
   
2. אם כל איברי סדרה אחת חיוביים, אז גם כל איברי הסדרה השנייה
   
נכון. כפל הסדרות שואף לאינסוף משמע מתקיים $a_{n}b_{n}>0$ מאחר ואיברי כמעט כל קבוצה אחת חיוביים, הרי שגם איברי השנייה, אחרת השאיפה הייתה למינוס אינסוף, או לא הייתה כלל (אם כל איברי הקבוצה השנייה היו 0). 
   
3. עבור אחת הסדרות, הגבול אינו אפס
   
לא נכון. ד.נ:
   
   $b=\frac{1}{\sqrt{ n }},a_{n}=n\sqrt{ n }$
   $\lim_{ n \to \infty }a_{n}b_{n}=\lim_{ n \to \infty }n\sqrt{ n } \frac{1}{\sqrt{ n }}=\lim_{ n \to \infty }n=\infty$
אבל $b_{n}$ גבול ידוע שווה לאפס. 
   
   
4. קיים $n>N,N\in \mathbb{N}$ כך ש $b_{n}\neq0$

נכון. זהה לתשובה מסעיף (2). אם כפל הסדרות שואף לאינסוף הסדרה השנייה אינה שלילית $a_{n}b_{n}>0$

5.  $\lim_{ n \to \infty }b_{n}=5\implies \lim_{ n \to \infty }a=\infty$

$\lim_{ n \to \infty }a_{n}=\lim_{ n \to \infty }a_{n}b_{n}=\lim_{ n \to \infty }a_{n}b_{n}\cdot \frac{1}{b_{n}}=\infty$

אבל $b_{n}=5$ ולכן $a_{n}=\infty$

6. אם $b_{n}<a_{n}$ כמעט לכל $n$ אז $\lim_{ n \to \infty }a_{n}=\infty$

לא נכון, ניקח $a_{n}$ שלילית אך בעלת גבול. ניקח $b_{n}$ שואפת למינוס אינסוף. מתקיים $b_{n}<a_{n},\lim_{ n \to \infty }a_{n}b_{n}=\infty$ אך ל $a_{n}$ קיים גבול.

7. אם $0<b_{n}<a_{n}$ כמעט לכל $n$ אז $\lim_{ n \to \infty }a_{n}=\infty$

נכון. ללא האפשרות למספרים שליליים הטענה נכונה שהרי אין שני סדרות סופיות שהכפל בניהן סופי. מאחר ו$a_{n}>b_{n}$ מתחייב שלפחות $a_{n}$ אינסופית.
